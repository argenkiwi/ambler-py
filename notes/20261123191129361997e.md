Rust gets a compile error (E0004) for an unwired outcome. In Python the walk's nested match statements have no `case _:` arm, and pyproject sets pyright strict plus reportMatchNotExhaustive = true, so removing a case gives "Cases within match statement do not exhaustively handle all values" (verified). A `case x: assert_never(x)` arm was tried first but pyright strict rejects it as reportUnnecessaryComparison ("Pattern will never be matched for subject type Never") because the match is already exhaustive. Gotcha: without the type check, a missing case falls through and step implicitly returns None, which silently halts the walk, so `uv run pyright` is part of the build, not optional. With mypy instead of pyright you would need the assert_never arm.
