`--state board:my_app.board.Board` used to be written verbatim, so nodes/__init__.py referenced `my_app` without importing it and pyright failed. utils/source.resolve_type now shortens each name-only attribute chain (`a.b.Type`, also inside generics like `list[a.b.Type] | None`) to `Type` and records `from a.b import Type`; every other name must be a builtin or already bound in nodes/__init__.py, otherwise the command exits 2 with a hint to give its path (issue #11 left reject-vs-warn open; we chose reject so generated code never fails pyright). A path whose last segment clashes with a name init already binds differently, or two --state items bringing the same name from different modules, also exits 2. render_protocols inserts the new import lines after init's last top-level import without sorting them, and the node scaffold now runs ScaffoldUtils.format (ruff isort + format) on the node, its test and init, as the walk scaffold does. Walks need no change: they read the import back from init via read_protocols.
