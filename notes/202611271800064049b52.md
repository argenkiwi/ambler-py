`state-protocols` (utils/conventions.py) treats a file as the state registry only when its project-relative path is exactly `src/<pkg>/nodes/__init__.py`, and as a node only when it is `src/<pkg>/nodes/<name>.py`. Any `class Has*(...Protocol...)` elsewhere, including tests, walks and utils, is a violation. That is why the bundled `examples/counter` was moved into a nodes/utils/walks layout like templates/py/example: with `HasCount` in the example's package `__init__.py` the convention was broken, even though check does not scan `src/ambler/examples` (SystemUtils.sources only reads nodes, walks, utils and tests). The rule does not reuse source.read_protocols or read_node: both drop line numbers, read_protocols silently filters non-field statements (the exact gap the rule closes) and read_node raises SourceError on files without a node shape. A node-local state is `State` plus any local class `run` takes as its state, so a renamed local protocol cannot dodge the rule. Registry contracts must also be named `Has` + to_pascal(field) and extend only `Protocol`, matching what scaffold_node writes.
