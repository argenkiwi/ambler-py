Ported from ambler-rs, where Node::run returns Result<Outcome, Error> and Walk::step returns Transition::{Next, Halt}. In Python, a node returns a member of its own Outcome(Enum) (UPPER_SNAKE members) and raises its module's Error(Exception), chained with `raise Error(...) from e`; a node that cannot fail defines no Error, and a terminal node returns None. Walk.step returns the next Id or None to halt, so there is no Transition type. The walk module exposes `Error` (an alias of a node error, or a walk-level exception) and `run()` through __all__, and __main__.main catches only that Error and calls sys.exit with a message. Node is a typing.Protocol satisfied structurally; nodes never subclass it.
