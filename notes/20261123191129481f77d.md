In ambler-rs, `amble check` maps a spec `###` heading to an Id variant by concatenating its words into CamelCase (Check M3U File -> CheckM3UFile). The Python port names Id members UPPER_SNAKE_CASE (Id.CHECK_M3U_FILE), matching the backtick-quoted ALL_CAPS edge references the specs already use, so headings can spell acronyms naturally. amble check has not been adapted to Python, so its heading-to-Id check would not match these enum members as is; if it is ported, map headings to UPPER_SNAKE instead. As in Rust, a node wired under two Ids needs a ### section for each.
