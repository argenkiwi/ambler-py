The ATP CLI (specs/cli.md, walks/cli.py) is one Walk: CLI_ROUTE pops argv[0] into state.command and fans out to SCAFFOLD_NODE/WALK/UTIL, RUN_CHECKS, CLI_HELP, CLI_ERROR. Nodes never sys.exit; they set state.exit_code (2 usage, 1 already-exists or no pyproject, the child's code for checks) and ambler.cli.main exits with the walk's result. Expected failures return Outcome.FAILED rather than raising, because the node has already printed and set the code; the walk maps DONE and FAILED alike to None. Each scaffolder parses its own argv with utils/args.ArgParser, whose error() raises UsageError instead of calling sys.exit (plain argparse would kill the process and bypass exit_code). File I/O goes through the shared ScaffoldUtils protocol (utils/fs.py, faked by tests/fakes.py FakeFs); source templates are pure functions in utils/templates.py and were verified byte-identical to the pre-refactor generator. Gotchas: State protocols must list Protocol last (class State(HasArgv, HasExitCode, Protocol)) or pyright treats them nominally and test dataclasses stop matching; pytest exit code 5 (nothing collected) is not a check failure; walk --no-runner is still a parsed no-op; tests/ has no __init__.py so pyproject sets pythonpath/extraPaths = tests for the shared fakes module.
