`ambler walk` (scaffold_walk + utils/source.py) parses each node with `ast` instead of importing it: importing would run project code and need its dependencies. It takes the Outcome members, whether `Error` exists, the Has* protocols from `run`'s state annotation (directly, or the bases of a local State protocol) and the Utils method signatures, which are copied as source text (not ast.unparse, which single-quotes strings) into the wiring test's Script. Types used in State fields or Utils signatures are imported from where the node or nodes/__init__ got them, not re-exported through the node module, so pyright and isort see ordinary imports. Rather than hand-wrapping long lines, the scaffold runs `python -m ruff check --select I --fix` and `ruff format` on what it writes (silently skipped when ruff is not installed), mirroring ambler-rs formatting generated Rust. Generic State fields need `field(default_factory=list[str])`, not `list`, or strict pyright reports a partially unknown type. Gotcha: ambler-py has no convention checker yet, so `check --lint-only` is just ruff + pyright.
