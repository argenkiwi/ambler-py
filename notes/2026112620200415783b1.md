`uv run ambler check` runs the `todo` convention (utils/conventions.py) before ruff, pyright and pytest, with or without --lint-only, over src/<pkg>/{nodes,walks,utils} and tests/. It only counts `raise NotImplementedError("not yet implemented")` and `raise NotImplementedError("not yet wired: NODE.X")` found with `ast`, never other mentions of the words, because ambler-py's own templates and tests contain those strings (in f-strings and asserts) and check runs on ambler-py itself. The module builds its markers in pieces ("not yet " + "implemented") for the same reason. Unparsable files are skipped and left to ruff/pyright. This is what makes ambler's e2e assertion that --lint-only fails on freshly scaffolded code hold for the right reason; before it, only a node-scaffold mock-type bug made it fail. The other rules `help check` lists are still not implemented.
