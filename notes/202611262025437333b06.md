`uv run ambler node x --state name` used to default the field's type to `object`, so the generated test's MockState declared `name: object` while `HasName` said `name: str`. Protocol attributes are invariant, so pyright rejected passing MockState to `run`. scaffold_node now resolves every --state field against nodes/__init__.py with utils/source.read_protocols, the same reader the walk scaffold uses. A typeless field takes its protocol's type and the imports that type needs, which go into the test. A typeless field with no protocol, or a typed field whose type differs from its protocol's (compared after ast.unparse normalisation), exits 2 before anything is written. This bug used to be what made ambler's e2e `check --lint-only` step fail on unfinished code; the todo rule does that now, so this fix is stacked on it.
